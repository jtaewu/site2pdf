# 03. 사용자 시나리오

## SC-01 URL 사이트 진단
**Given** 소유/수집 승인이 있는 HTTPS URL과 범위 설정이 있고 **When** audit를 실행하면 **Then** origin, 리다이렉트, robots, 예상 문서 링크와 위험을 진단한다.

## SC-02 하위 페이지 탐색
**Given** 메뉴/본문 링크가 있는 사이트가 있고 **When** discover를 실행하면 **Then** 지정 origin/path 내 URL만 깊이·페이지 수 제한 아래 수집해 manifest를 생성한다.

## SC-03 PDF 대상 선택
**Given** 발견된 50개 URL이 있고 **When** 구성 파일에서 10개를 제외하면 **Then** 40개만 변환되고 제외 사유가 기록된다.

## SC-04 통합 PDF
**Given** 선택 페이지와 사용자 지정 순서가 있고 **When** generate를 실행하면 **Then** 지정 순서의 페이지별 PDF 및 통합 PDF를 만든다.

## SC-05 그룹별 PDF(Should)
**Given** `/docs/api/`, `/docs/sdk/` 그룹 설정이 있고 **When** generate를 실행하면 **Then** 그룹별 PDF를 선택적으로 만든다.

## SC-06 코드/표/이미지
**Given** 한글, 긴 코드, 넓은 표, 외부 이미지가 있고 **When** 변환하면 **Then** 지원 가능한 리소스를 안전하게 렌더링하고 누락/잘림 여부를 검수할 수 있다.

## SC-07 범위 이탈 링크
**Given** 페이지에 외부 도메인/로그아웃/관리자 URL이 있고 **When** 링크를 발견하면 **Then** 탐색·출력에서 제외한다.

## SC-08 위험한 리다이렉트
**Given** 승인된 URL이 localhost/사설 IP/클라우드 메타데이터로 리다이렉트하면 **When** 요청을 시도하면 **Then** 차단하고 원인 보고서를 남긴다.

## SC-09 동적 SPA
**Given** 클라이언트 렌더링 사이트가 있고 **When** 페이지 로드를 기다리면 **Then** 타임아웃 상한 안에서 렌더링을 확인해 PDF를 생성하거나 실패를 기록한다.

## SC-10 로컬 오프라인
**Given** 로컬 정적 빌드가 있고 **When** `--source`로 변환하면 **Then** 외부 인터넷 요청 없이 PDF를 만든다.

## SC-11 차단된 사이트
**Given** 접근 차단/401/403/캡차가 있고 **When** 변환을 시도하면 **Then** 우회하지 않고 중단한다. 승인된 로컬 빌드 제공을 안내한다.

## SC-12 재실행/장애
**Given** 20개 중 2개가 실패했고 **When** 결과를 확인하면 **Then** 성공 18개/실패 2개와 이유를 보여주고 전체 성공으로 표기하지 않는다.
