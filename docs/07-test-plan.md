# 07. 테스트·인수 계획

## 1. 필수 테스트
| ID | 테스트 | 기대 결과 |
|---|---|---|
| T-01 | 정상 HTTPS URL 입력 | 진단·탐색 가능 |
| T-02 | 잘못된 스킴/URL userinfo/위험 포트 | 거부 |
| T-03 | localhost, 사설·링크로컬·IPv6·메타데이터 목적지 | 전부 차단 |
| T-04 | 공개 도메인→사설 IP 리다이렉트 | 차단 |
| T-05 | DNS 재바인딩/연결주소 변조 시뮬레이션 | 연결 차단 검증 |
| T-06 | 외부 도메인/경로 prefix 밖 링크 | 탐색하지 않음 |
| T-07 | 루프 링크·쿼리 조합·중복 URL | 페이지 제한/중복제거 작동 |
| T-08 | robots 거부·접근 차단(401/403)/캡차 | 우회 없이 중단 |
| T-09 | minDelay/maxDepth/maxPages/timeout | 실제 제한 준수 |
| T-10 | 사용자가 선택 제외한 문서 | PDF 미포함, 사유 기록 |
| T-11 | 정적 HTML 사이트 | 페이지별+통합 PDF 생성 |
| T-12 | JS 렌더링 SPA | 지정 타임아웃 내 렌더링/실패 표시 |
| T-13 | 한글·영문·긴 코드·넓은 표·이미지 | 샘플 PDF 육안 검사, 잘림 없음 |
| T-14 | 이미지 실패/iframe/동영상 | 경고 또는 명시된 실패 처리 |
| T-15 | 병합 PDF 순서/중복 | manifest와 일치 |
| T-16 | 로컬 폴더·심볼릭 링크 탈출 | 루트 외 파일 차단 |
| T-17 | 로컬 오프라인 모드 | 외부 요청 0건 |
| T-18 | 출력 경로 탈출/악성 파일명 | 안전한 파일명·경로만 생성 |
| T-19 | 브라우저 오류/부분 실패 | 전체 성공으로 위장하지 않음 |
| T-20 | 페이지 접근/렌더링 중 민감정보 | 로그에 비밀값 노출 없음 |

## 2. 테스트용 사이트 구조
- `fixtures/static-site`: 계층형 메뉴/상대 경로/이미지/표/코드
- `fixtures/spa-site`: JS 라우팅/지연 렌더링
- `fixtures/cyclic-site`: 순환 링크/중복/쿼리 파라미터
- `fixtures/blocked-site`: 403/robots/리다이렉트
- `fixtures/security-site`: mock DNS, SSRF, 출력 경로 공격
테스트 네트워크는 **통제된 격리 환경**에서만 사용. 실제 공격 대상 탐색 금지.

## 3. PDF 검수 체크리스트
- [ ] 발견·선택·최종 포함 URL 개수와 순서 일치
- [ ] 제목/한글/코드/표/이미지 잘림 없음
- [ ] PDF 텍스트 복사·검색 가능
- [ ] 페이지 수·병합 순서·파일명 정상
- [ ] 페이지별 에러/누락 리소스가 manifest에 표시
- [ ] 외부 배포 대상은 저작권·민감정보 검수 완료

## 4. 완료 조건
Must 기능 테스트 통과 + 서로 다른 구조의 샘플 사이트 2종 이상 + 보안 테스트 필수 항목 통과 + 수동 PDF QA. Should 실패는 별도 한계로 명시.
