## 현재 가정
- UI 없는 **CLI MVP**가 최초 목표, 범용 스크랩 SaaS는 아님.
- 원격 HTTPS의 승인된 동일 출처·경로 내부만 탐색하며, 인증·차단 우회 기능은 제외.
- 모든 웹사이트에서 100% 똑같은 시각적 변환을 보장할 수 없다.
- KICC 문서 사이트의 실제 기술 스택 및 배포 승인 범위는 확인되지 않았다.
- 이 파일들은 개발 지침이며 프로그램 구현은 포함하지 않는다.
